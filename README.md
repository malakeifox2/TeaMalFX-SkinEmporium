Originally I Intended to do just an update to my WIndows 7 Dark Skin, However I realized the potential, I decided to have the skins I done into one file, mainly because ever since the release of my Dark 7 Skin I had done more.
      
My motivations is to polish these skins for my use.

Windows 7 Dark
- A dark mode version, WIP

Windows 7 (Aero 10.1) 
- A variant of Windows 7 Dark, which is made for use with Aero 10.1

VISTALike Remastered
- My polished version of the original Vistalike.

VISTALike Dark
- A dark mode version of the Vista Startmenu. I'm pretty sure im like the only one who attempted this.

Windows 8 and Windows 8 Dark Remastered
- My polished takes on these two, they aren't accurate to Windows 8 RT's Start Menu, but they do certainly fit well with the taskbar and Window 10's too.

Added features is much better glass for the 8 skins (i tried), padding options, disable transparency (great for windows 7 basic themes) 120 DPI.



Questions:

Can I remix these skins?
- Of course. I feel like im the only one whos doing something with Openshell
Is this accurate?
- Not 100% but my goal is to be almost as accurate.
Does this restore glass?
- The skin itself does not restore glass, accurately it has support for it. To restore openshell glass on new versions like Windows 11 use DWMBlurGlass or Openglass
